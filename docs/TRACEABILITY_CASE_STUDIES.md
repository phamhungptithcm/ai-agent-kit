# Traceability case studies

## Recover a wrong turn

Record the original decision, approval, implementing run, and affected files.
Append the later superseding decision. `ai-agent-kit why` shows both choices;
the recovery command previews reconciliation without resetting Git.

## Block an over-privileged plugin

Activate a signed fixture with read-only source access. Request process or
network authority outside its manifest/task ceiling. Invocation returns
`DENIED` and records a receipt. Modify the installed manifest and the next
invocation returns `QUARANTINED`.

## Resume on another agent

Checkpoint a run with decision and evidence references, export a redacted
`.aakrun`, then verify it on another supported host. Inspection works without
trusting the original chat. Resume stays preview-only until repository drift,
adapter capability, plugin hashes, policy, and approval are reconciled.

These examples use local fixtures. They demonstrate contracts and failure
behavior, not the quality of an unobserved production agent.
