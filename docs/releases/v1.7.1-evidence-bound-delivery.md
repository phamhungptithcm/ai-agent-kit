# v1.7.1 — Evidence-Bound Product Delivery

AI Agent Kit v1.7.1 adds evidence-bound delivery after Product Genesis: source-linked business rules, specifications and design, measurable engineering controls, candidate-bound checks, independent review, and release readback.

## Release sanity corrections

- Initialize the clean-install repository before package postinstall, matching the supported Git-repository installation contract.
- Allow temporary npm registry processing delays with a finite retry budget; permanent errors and incorrect artifacts still block acceptance.
- Preserve immutable v1.7.0 history; this patch is the recommended release.

## Highlights

- Adds the `delivery` CLI for execution evidence while preserving the published `product` Product Genesis commands.
- Introduces AAK-PRODUCTION-1 with 21 document, planning, engineering, security and operational controls; missing evidence remains visible.
- Binds document revisions, acceptance criteria, implementation scope, execution receipts and signed review to the current candidate.
- Adds a clean eight-step progress view with purpose, expected output, actual locations, blockers and review evidence.
- Adds safe product-flow inventory and agent-operated CLI resolution for natural-language intake.
- Strengthens release artifact freezing and exact published-package integrity/readback checks.

## Compatibility and boundaries

Existing Product Genesis commands remain available. Evidence-bound execution uses `ai-agent-kit delivery`; `ai-agent-kit start` creates a delivery flow. Existing legacy review history is readable but cannot establish production acceptance. Trusted reviewer/operator enrollment remains an authorized operator responsibility.

The progress view is a saved snapshot. Instruction-only host routing remains advisory. Local/fixture checks and signatures do not certify document semantics, unrestricted natural-language routing, live production outcomes or usability by every novice. Complete clean-repository Claude Code/Codex LLM journeys have not been certified in this release.

## Install

```bash
npm install -g @hunpeolabs/ai-agent-kit@1.7.1
```

Bootstrap inside your repository with the adapter you use. Describe your goal normally; Product Genesis handles discovery and approvals, and the delivery harness records execution evidence.
