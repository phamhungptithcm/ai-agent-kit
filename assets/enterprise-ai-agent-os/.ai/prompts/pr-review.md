# PR Review Prompt

```text
Use the code-review skill.

Review this change as a senior production engineer.

Prioritize correctness, security, data integrity, concurrency, backward compatibility, reliability, performance, observability, testing, and maintainability.

For every finding provide:
- Severity
- Location
- Problem
- Production impact
- Reproduction or evidence
- Recommended correction

Also report missing tests, deployment risk, migration risk, rollback concerns, and areas reviewed with no issue found.
```
