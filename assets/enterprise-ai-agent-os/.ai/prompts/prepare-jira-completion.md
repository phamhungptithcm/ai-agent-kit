# Prepare Jira Completion Prompt

```text
Use the jira-completion-package skill.

Prepare a copy-ready Jira completion comment with:
- RCA
- Solution
- MR/PR
- Acceptance criteria
- Validation
- Docs/specs/diagrams
- Demo package
- Deployment/rollback
- Risks/blockers/follow-up

Include a Markdown table mapping screenshot placeholder IDs to the exact screen or evidence the developer must capture manually.

Do not update Jira unless an approved authenticated Jira connector is available, the issue key is verified, permission is confirmed, and the response is successful.
```
