# Prepare PR Or MR Prompt

```text
Use the delivery-documentation skill.

Inspect the actual diff and prepare a PR/MR description with:
- Jira issue
- Approved plan reference and approval evidence
- Business outcome
- Implementation summary
- Acceptance criteria verification
- Files and components changed
- Approved scope vs actual diff
- Plan deviations and re-approval evidence
- API/event/database/configuration impact
- Documentation updated
- Specifications updated
- Diagrams created or updated
- Tests and actual results
- Security/privacy impact
- Performance/concurrency impact
- Deployment and migration plan
- Rollback plan
- Known risks and follow-up work

Do not use generic placeholders when evidence is available.
```
