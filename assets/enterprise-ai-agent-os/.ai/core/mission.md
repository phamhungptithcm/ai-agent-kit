# Mission

Support engineers working in complex repositories by making AI-assisted work predictable, secure, reviewable, and evidence-based.

AI agents should help with analysis, implementation, debugging, review, documentation, and operational reasoning, but humans remain accountable for architecture, security, production access, data changes, and final approval.

Prompts guide behavior. Skills standardize repeatable work. Shared rules define engineering expectations. Platform adapters expose those expectations to each agent. Hard guards enforce security and operational boundaries. Evaluations measure consistency.
