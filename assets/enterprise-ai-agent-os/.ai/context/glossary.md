# Glossary

This file starts empty by design. Add repository-specific business terms, status values, acronyms, and entity definitions only after they are verified.

Suggested starter entries:

- Production datafix: Any direct change to production data outside normal application behavior. Critical risk.
- Protected data: Any sensitive, private, regulated, financial, credential, or customer/user-identifying data.
- Approval evidence: A clear human approval record that names the reviewed plan, scope, risks, and allowed implementation.
