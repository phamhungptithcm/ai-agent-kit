# Repository Map

This file is a reusable placeholder. Replace it with facts from the target repository after running the Repository Intelligence Gate.

Document only information verified from source files, build configuration, tests, deployment scripts, or approved team knowledge.

Suggested sections:

- Top-level directories and their purpose.
- Main application entry points.
- Shared libraries and internal packages.
- Database, migration, and schema locations.
- CI/CD and release automation.
- Test commands and test ownership.
- External integrations and boundaries.
- Generated files and files that should not be edited directly.

Agents must use CodeGraph and CocoIndex first, then inspect target files before assuming build commands, test framework, ownership, runtime behavior, or domain meaning.
