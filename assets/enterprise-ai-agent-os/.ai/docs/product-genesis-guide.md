# Product Genesis Agent Guide

Start with `start-product` when the user has an idea but no approved product baseline. Load `.ai/core/product-genesis.md`, the stage-specific skill, relevant quality profiles, and only the artifacts needed for the current gate.

Keep discussion interactive and accessible to non-technical users. Summarize confirmed facts, assumptions, unknowns, and changes after each round. Use stable IDs and successor versions so an agent or human can resume without relying on chat history.

Never advance from BRD or specification review without a named human approval record bound to the exact artifact hash. Never start implementation merely because the documents are complete. Route material deviations through change control and classify all final evidence by environment.
