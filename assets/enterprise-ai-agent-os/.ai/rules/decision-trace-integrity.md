# Decision Trace Integrity

- Give each material decision and run a stable unique ID.
- Append immutable events linked by previous hash; record corrections as later events.
- Preserve goal, scope, constraints, alternatives, assumptions, approval, execution, verification, and outcome.
- Bind evidence by stable references and content hashes where available.
- Reject duplicate event IDs, broken chains, fabricated checks, silent rewrites, and sensitive values.
- A final report must identify the latest verified event and unresolved uncertainty.
