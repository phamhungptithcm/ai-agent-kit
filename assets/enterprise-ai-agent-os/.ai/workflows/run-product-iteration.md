# Run Product Iteration Workflow

1. Require current solution and delivery approvals.
2. Set one outcome-oriented iteration goal and commit only traceable backlog items within measured capacity.
3. Bind plan to current solution/delivery hashes and Definition of Done.
4. Implement/review working vertical slices continuously. Keep discovery, failures, security, tests, operations, and documentation visible.
5. Record acceptance with evidence receipts. Do not mark an item accepted from author assertion alone.
6. Propagate material discoveries to successor artifacts and reapproval; never hide scope change inside progress status.
7. Complete review and retrospective with unfinished work, capacity variance, quality debt, and improvement action.
8. Run convergence on a clean tracked commit before production readiness.
