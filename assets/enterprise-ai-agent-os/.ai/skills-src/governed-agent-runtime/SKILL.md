# Governed Agent Runtime

Use this skill for protected implementation, unattended low-risk work, policy explanations, evidence verification, or audit preparation.

Create one task identity and capability per approved change. Advance states sequentially with actual evidence. Evaluate every protected action before execution. Stop on `ask` or `deny`. Never reuse expired capabilities, expand paths, increase risk, or change action parameters after authorization.

Declare the goal and measurable acceptance criteria. Record sourced facts separately from assumptions. Revise the plan when evidence contradicts an assumption, a check fails, or the impact boundary changes; include the trigger and do not repeat an unchanged failed strategy.

Record privacy-minimized receipts. Do not store prompts, chain-of-thought, secrets, source contents, or raw command output. Before completion, run independent evidence verification and compare the actual diff to tracked approval.

Propose reusable memory only from verified outcomes with provenance and confidence. Memory remains unavailable for retrieval until a named human approves it.
