# Operate Product

1. Resume the exact released candidate and environment attestation.
2. Track SLO/error-budget, alert, incident, support, cost, adoption, retention, and product-outcome evidence by measurement window.
3. Distinguish telemetry configuration from live observations. Bind live receipts to the released commit and environment.
4. Triage incidents through authorized operational workflows; do not infer production mutation authority.
5. Compare actual outcomes with BRD goals, business-case assumptions, pricing, capacity, and support load.
6. Create a successor hypothesis, backlog/version change, rollback, hold, or retirement proposal. Material changes propagate through affected approvals.

Report live, stale, missing, and not-applicable evidence separately.
