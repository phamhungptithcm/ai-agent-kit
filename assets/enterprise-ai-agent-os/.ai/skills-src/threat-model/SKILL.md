# Threat Model

Use this skill before or during high-risk design and security review.

## Required Work

1. Define assets, actors, trust boundaries, entry points, data stores, external dependencies, and privileged operations.
2. Use repository intelligence to identify real code paths, APIs, jobs, queues, databases, configs, and deployment boundaries.
3. Identify threats across spoofing, tampering, repudiation, information disclosure, denial of service, elevation of privilege, supply chain, and operational misuse.
4. Map threats to existing controls and missing controls.
5. Prioritize mitigations by risk and implementation timing.

## Output

Return a concise model with scope, diagram or data-flow summary when useful, threats, controls, gaps, required mitigations, assumptions, and open questions. Mark anything needing human security approval.
